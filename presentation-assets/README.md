## How to save them

1. Open this chat in your browser
2. Right-click each screenshot → **Save image as…**
3. Save to this folder with the exact filename from the table above
4. Reload `presentation-full.html` — the screenshots appear automatically

> Filenames are case-sensitive. Anything missing shows a dashed placeholder with the filename it expects, so you can always see what to add.
