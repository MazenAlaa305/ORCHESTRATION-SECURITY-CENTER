# .gitignore — Documentation

## File Purpose

Specifies intentional untracked files that Git should ignore across the entire repository. This prevents sensitive credentials, build artifacts, runtime caches, and OS-specific metadata from being accidentally committed.

## Key Exclusion Categories

### Credentials & Secrets
- `.env` files at any level of the project tree — prevents API keys, database passwords, and Wazuh credentials from entering version control.

### Python Artifacts
- `__pycache__/` directories — Python bytecode cache folders generated at runtime.
- `*.pyc` / `*.pyo` / `*.pyd` — Compiled Python bytecode files.
- `*.egg-info/` — Python package distribution metadata.
- `venv/`, `.venv/` — Virtual environment directories containing installed dependencies.
- `instance/` — SQLite database files and Flask/FastAPI instance folders.

### Node.js Artifacts
- `node_modules/` — Installed NPM packages (can be hundreds of MB).
- `dist/` — Vite production build output directory.
- `*.local` — Vite local environment files.

### Testing & Coverage
- `.pytest_cache/` — Pytest run caches.
- `htmlcov/`, `.coverage` — Coverage report outputs.

### IDE & OS Files
- `.vscode/settings.json` (sensitive parts) — User-specific editor settings.
- `*.DS_Store` — macOS Finder metadata files.
- `Thumbs.db` — Windows Explorer thumbnail cache.

## Dependencies

- **Enforced by**: Git version control system across the entire repository.
