# components/dashboard/AssetDetailPanel.jsx — Documentation

## File Purpose

Displays **comprehensive detail for a selected network asset** (11,296 bytes), including OS fingerprint, discovered services, AI-generated intelligence insights, and historical scan data.

## Key Components

### `AssetDetailPanel({ asset, onClose })`
A detail panel (either slide-in drawer or embedded panel) showing all information about a network host.

**Header**: IP address (large), hostname, MAC address, MAC vendor, and device type icon.

**OS Information**: OS name, OS family, accuracy percentage shown as a confidence indicator.

**Services Table**: A sortable table of all `AssetService` records for the asset with columns: Port, Protocol, State (open/filtered/closed badge), Service Name, Product, Version, CPE string.

**AI Intelligence Insight Section**: Displays the `ai_insight` JSON generated by `IntelligenceAgent`:
- Device classification label (e.g., "Web Server")
- Risk summary paragraph
- CVE hints list with links to NVD database
- Analyst notes

**Risk Indicators**: Color-coded risk level badge, criticality classification, and risk score for the asset.

**Vulnerability History**: A compact list of vulnerabilities associated with this asset's IP/hostname from past scans.

**Actions**: "Scan This Asset" button that pre-fills the scan target with the asset's IP address.
