# components/dashboard/Reports.jsx — Documentation

## File Purpose

Provides the **PDF security report download interface** (6,133 bytes), listing all completed scans that have reports available and allowing users to download them with a single click.

## Key Components

### `Reports({ scans })`
Renders a list of completed scans as downloadable report cards.

**Report Card Display:**
Each card shows: scan target URL, completion date, vulnerability count, risk score badge, and a "Download PDF Report" button.

**Download Logic:**
Clicking the download button calls `GET /api/v1/reports/{scan_id}`. The response is received as a `Blob` and a temporary anchor element is created with a generated URL to trigger the browser's file download dialog. The filename is formatted as `report_{target}_{date}.pdf`.

**Loading State:** The download button shows a spinner while the PDF is being generated by the backend.

**Empty State:** When no completed scans exist, shows a "No reports available — complete a scan to generate your first report" message with a call-to-action button to navigate to the Scans tab.
