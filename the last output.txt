Proposed first task: #9 — Framework / Dedup / CVSS chips on findings.

Why first: purely additive, zero risk to existing behavior, ~2 files (VulnerabilitiesPanel.jsx, IncidentDetailDrawer.jsx). The backend already emits control_tags (OWASP/CWE/ISO/NIST/PCI), cve_id, cvss_score, and a dedup count is computable from finding_id groupings (already done in the panel). Today this data is partially shown only inside the drawer — chips bring it onto the row so triage can pivot by framework without opening each.
What changes: each row gets compact chips for severity, CVE, CVSS, MITRE/OWASP, and ×N hosts when deduped. Chips are clickable to apply as filters
